## CLEARANCE LEVEL: INFRARED (Beginner Prompts)

### The Basic Pattern That Actually Works™
```markdown
Role: You are a patient senior developer doing code review
Task: Review this [language] code for a junior developer
Context: This is for [project type] that needs to [goal]
Code: [paste code]
Focus: Identify the TOP 3 issues and explain WHY they matter
Output: Actionable fixes with example code
```

### Debugging Prompt That Gets Answers™
```markdown
I'm a student learning [language/framework].
My code should [expected behavior].

Error message: [exact error]

Code:
```[paste code]```

I've tried:
1. [attempt 1]
2. [attempt 2]

Walk me through debugging this systematically like you're teaching.
```

## 📊 PROMPT QUALITY METRICS™

Rate your prompts before sending:

### The S.P.E.C. Score™
- **S**pecific: Is the goal clear? (0-25 points)
- **P**ersona: Did you define Claude's role? (0-25 points)
- **E**xample: Did you include code/context? (0-25 points)
- **C**onstraints: Did you specify limits/format? (0-25 points)

**Score 50-75:** Acceptable velocity
