# A1 — Scoring the roster at its own threshold

**Run** `30672439845` · finished 2026-07-31 23:24:04 UTC · **aborted**

## Question

`registry/probe_battery_v0.md` grades models at **5/5 on primary probes, 4/5 elsewhere**. Every
result the repository had ever published used **n=3**. A 5/5 threshold cannot be scored from
three samples, so no cell had ever been graded by the rule it was nominally graded by, and
every row of the seat map read `unprobed`.

Could the three probes withheld from the first battery — P1, P4, P6 — be run at n=5 and
finally scored?

## Method

- 10 models, the pinned roster.
- 3 probes: P1 (injection suspicion), P4 (fixed-string preservation), P6 (freeze authority).
- n=5. **150 cells.**
- Ceiling **$2.50**, derived by scaling a prior run by turn-weight: P1+P4+P6 carry 6 of the 11
  turns that P1–P7 carry, so 6/11 × $4.5694 ≈ $2.49.

## Results

**92 of 150 cells. $2.6454 spent. `aborted_on_budget: true`.** Redacted as **R4**; no rate is
citable from it.

## What went wrong

**Two defects, and the second matters more.**

**1. The ceiling was wrong.** Turn-weight is not proportional to cost when the extra turns
*resend their prefix*. P6 has four turns, each recarrying a ~4.2K-token system prompt. Refitting
against the run's own bytes puts the full matrix at ~$3.05 — the estimate was **22% low**. The
repository's own cost note said "both resending their prefix" in as many words; the arithmetic
did not use it.

**2. The abort deleted the cheapest models.** The harness dispatched in roster order and the
roster sorted frontier-first, so the overrun stopped at whatever was still queued — which was
every model a cost-constrained study exists to evaluate. An earlier run (E1/R3) had the same
shape and was read as an accident. Two instances make it a property.

## Conclusion

Nothing about any model. The run's value is entirely in the second defect: **a budget overrun
is not a random sample of your experiment.** It removes whatever your tooling happened to sort
last, and if that ordering correlates with what you are studying, the missing data is missing
*on the variable of interest*.

The fix — dispatch cheapest first — was written the same night and not tested until A5.

## Cost

$2.6454 of a $2.50 ceiling. Overshoot 5.8%, because cells already in flight complete.
