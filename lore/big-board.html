Model ledger

Pass rate is pass / (pass + fail), pooling every probe and every run, so it is a crude aggregate and not a seat verdict: a model that drew harder probes reads worse. blend is (12×input + output) / 13 USD per 1M, weighted that way because these probes resend a ~4.2K-token edition on every turn.
